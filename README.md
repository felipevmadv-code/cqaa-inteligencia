# CQAA Inteligência

Sistema interno de contratos de honorários, recebimentos e comissões do CQAA.

Esta página contém **apenas o programa**. Nenhum dado do escritório fica aqui: contratos, lançamentos, usuários e anexos ficam
criptografados na pasta "Dados" do OneDrive e só podem ser lidos com usuário e senha válidos.

Para abrir: use o Google Chrome ou o Microsoft Edge (Windows ou Mac) e, no endereço do site, escolha "Instalar aplicativo".
